# 港口岸电使用核算系统

记录船舶靠港期间的岸电接电时长与用电量，按航次出具对账明细，供船方与港方双方核对确认。

## 功能

| 模块 | 说明 |
|------|------|
| 仪表盘 | 当前接电中船舶、本月用电量/电费、待确认对账单概览 |
| 船舶档案 | 船名、IMO 编号、船公司登记 |
| 航次管理 | 船舶靠港登记（航次号、泊位、靠泊/离泊时间） |
| 接电记录 | 办理接电（记录接电点、起始表码、倍率）；断电结算自动计算**接电时长**与**用电量** |
| 电价设置 | 多电价方案管理，对账单按出具时的执行电价计费并留存快照 |
| 对账单 | 按航次汇总出具，含每条接电明细（起止表码、时长、电量、金额）；**船方确认 → 港方确认** 双方确认流程，支持异议登记与重新出具，可打印 |

## 业务流程

```
船舶靠港 → 登记航次 → 办理接电 → 断电结算（自动核算时长/电量）
        → 出具对账单 → 船方确认 → 港方确认 → 完成
                          ↓
                        有异议 → 港方核实 → 重新出具
```

## 运行

```bash
npm install
npm start          # 默认 http://localhost:3000，PORT 环境变量可改端口
```

技术栈：Node.js + Express + sql.js（WASM SQLite，无需编译）。数据持久化在 `data/shorepower.db`，首次启动自动建表并写入演示数据。

## 核算规则

- **用电量** =（结束表码 − 起始表码）× 互感器倍率
- **接电时长** = 断电时间 − 接电时间（分钟）
- **电费** = 用电量 × 执行电价（出具对账单时快照保存，事后调价不影响已出具单据）
- 校验：结束表码不得小于起始表码；断电时间必须晚于接电时间；存在接电中记录时不可出具对账单、不可办理离港；已计入对账单的接电记录不可删除
- 对账单进入确认流程（船方/双方已确认）后不可重新出具；异议状态可作废重出
